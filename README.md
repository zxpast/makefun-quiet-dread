## What it does

single-line code review comment to `$MAKEFUN_OUTPUT_DIR/entry.txt` — a comment
that approves a pull request while carrying quiet existential dread:

> Approved. The diff is small, the tests pass, and the comment I deleted was the only one that understood this file.

byte-identical output.
